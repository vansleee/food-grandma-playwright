# Food Grandma 的三個網頁測試

## CH15-T01 餐廳管理者登入後看到訂單管理

前置：有可用的餐廳管理帳號，目前尚未登入。

步驟：
1. 開啟餐廳後台登入頁面。
2. 輸入正確的帳號與密碼，按下「登入」。

預期結果：
- 頁面路徑為 `/management/orders`。
- 顯示「訂單管理」標題與訂單表格。

## CH15-T02 指定訂單變成待取餐

前置：餐廳管理者已登入訂單管理頁面。餐廳有一筆「備餐中」的訂單，並已記下訂單編號。

步驟：
1. 依訂單編號找到指定訂單，確認目前為「備餐中」。
2. 按下該筆訂單的「備餐完成」。

預期結果：
- 同一筆訂單顯示「待取餐」。
- 該筆訂單的「備餐完成」按鈕消失。

## CH15-T03 外送員確認送達後，餐廳看到同一筆訂單已送達

前置：餐廳管理者已登入訂單管理頁面。外送員只有一筆進行中的配送，並已記下訂單編號。管理者與外送員各自使用獨立的瀏覽器登入環境。

步驟：
1. 餐廳管理者依訂單編號確認該筆訂單顯示「配送中」。
2. 外送員從「體驗登入」進入工作台，再開啟進行中配送，確認指定編號的訂單出現在清單中。
3. 外送員按下該筆訂單的「確認已送達」。
4. 餐廳管理者重新整理訂單清單，查看同一筆訂單。

預期結果：
- 外送員畫面顯示「目前沒有進行中的配送」。
- 餐廳後台原訂單編號的狀態為「已送達」。
