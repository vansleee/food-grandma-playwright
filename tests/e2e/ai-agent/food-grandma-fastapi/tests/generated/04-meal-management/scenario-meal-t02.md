# MEAL-T02 修改價格後更新同一筆餐點

依已核准 specs/04-meal-management.md 的 MEAL-04。

- 每案以 API 建立自己的測試餐點，原價 120、獨立名稱與描述；不重用 ID 23。
- 記錄建立回傳的 ID、原始欄位及自己餐廳的餐點 ID 集合。
- 登入管理網站，從列表按該 ID 的餐點編輯連結。
- 確認原始名稱、描述與價格 120 已載入，再由 UI 改為 150 並儲存。
- 檢查同 ID 新價格、名稱及描述不變、餐點 ID 集合不變。
- API 回讀同 ID 為 150；重新開啟編輯頁價格仍為 150。
- 只操作 localhost 可重建示範環境；不做全域 reset，不修改既有餐點。不發明刪除 API；新增專用資料可保留並回報 ID。
- API 在 http://localhost:8081；管理 UI 在 http://localhost:8082/management/。
- 此情境已完成一次 UI 人工監督操作；本輪是代理產出與獨立測試驗證。
