# 外送員接單功能現況線索

狀態：整理用線索，尚未在本次練習中重新查核或執行驗證。不得把現況線索直接當成已核准的產品需求。

## UI 線索

- 外送員可接取訂單的畫面稱為「可接訂單」。
- 進行中配送畫面可由 `/driver/delivery` 開啟，畫面使用中文標示。
- 接單操作名稱為「接取訂單」。
- 配送中的訂單提供「確認已送達」操作。
- 接單成功後應能在進行中配送畫面看到該筆訂單。
- 先前的規格文件曾記錄 API 回傳英文訊息 `Your outstanding order is not delivered yet.`；這與需求草稿預期的中文接單上限訊息不同。此處只是舊文件記載，尚未重新查核目前 UI/API，請列為待審查差異，不要自行判定哪個訊息正確。

## API 線索

- 既有文件記錄的接單 API 候選為 `POST /api/driver/orders/{order_id}/claim`。
- 既有文件記錄此 API 以 form 欄位傳入 `access_token`。
- endpoint、請求格式、回應格式及錯誤狀態都應由 AI 標示為待查核線索，不要當成已驗證契約。
